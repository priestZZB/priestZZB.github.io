IDEA是Java后端开发的“标配”工具，原生功能已经很强大，但搭配合适的插件，能让开发效率翻倍——告别手动写代码、自动检查语法错误、快速生成配置文件…作为一名本科计算机生，从入门到做实习项目，我筛选出了8个**刚需、轻量、无广告**的IDEA插件，覆盖代码编写、语法检查、项目开发、效率提升，新手直接装就行。

### 1. Lombok
最核心的插件！通过`@Data`、`@Getter`、`@Setter`、`@NoArgsConstructor`等注解，自动生成实体类的get/set/toString/构造方法，省去大量重复代码，让实体类更简洁。

### 2. Alibaba Java Coding Guidelines
阿里巴巴Java开发手册插件，实时检查代码中的不规范问题（如命名不规范、空指针风险、集合使用不当），给出修复建议，强制养成规范的代码习惯，实习面试中代码规范很重要！

### 3. MyBatisX
MyBatis开发神器，支持Mapper接口和Mapper.xml双向跳转、自动生成CRUD代码、一键生成实体类，告别手动写SQL和映射文件。

### 4. Free MyBatis Plugin
和MyBatisX互补，适合习惯传统MyBatis开发的同学，支持接口和xml的快速跳转、生成注解式SQL，轻量无负担。

### 5. CodeGlance Pro
在IDEA右侧生成代码迷你地图，支持快速点击跳转，浏览长代码时不用反复滑动滚轮，尤其适合看别人的项目代码。

### 6. Grep Console
自定义IDEA控制台日志颜色，不同级别（INFO/ERROR/DEBUG/WARN）的日志显示不同颜色，快速定位异常日志。

### 7. Maven Helper
Maven项目必备，一键查看依赖树、分析依赖冲突、排除冲突的依赖，解决Maven项目中最头疼的“依赖问题”。

### 8. Translation
支持多种语言互译，选中代码中的英文注释、关键字，一键翻译，看国外源码、写英文注释时超方便。

### 避坑提醒
插件不是越多越好，装太多会导致IDEA卡顿，以上8个都是轻量且实用的。另外，建议开启IDEA的**自动导入包**和**代码自动格式化**，配合插件效果更佳。

### 总结
工具的核心是“提升效率，减少重复工作”，这8个插件能让我们把更多精力放在核心业务逻辑上，新手装完后花10分钟熟悉用法，开发效率会显著提升。
